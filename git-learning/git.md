# What a commit is?
- A **commit** is a state of a project that has been saved.
# What a branch is?
- A **branch** is a pointer to the commit.
# What HEAD is?
- **HEAD** is the label for current branch or commit you are in.
# The difference between merge and rebase?
- **Merge** of two commits creates a child commit which is pointed to both parents, and rebase just adds commits of a branch on top of the base branch to which it is being rebased.
# What HEAD~2 and main^ mean?
- **HEAD~2** is a commit 2 steps before the HEAD branch, main^ is a previous commit of the main branch.
