# What does git cherry-pick C2 C4 do?
- *Git cherry-pick C2 C4* chooses commits c2 and c4 and copies them on top of the HEAD commit.
# What can you do with git rebase -i HEAD~4 (name at least three things)?
- *Git rebase -i HEAD~4* can rearrange commits, remove them and rename them.
# What is a tag, and how is it different from a branch? 
- *Tag* is an anchor, permanent label for a significant changes in the project, tag can not change its position even if new commits made.
